# Core Hypotheses

## H1 EMBEDDING SHIFT

**Claim:** K6/K7 markers produce embedding displacement greater than 3 sigma from the C0/C1/C2 median baseline.

**Formal:** 

**Operational:** mean_z_K6 > 3 and mean_z_K7 > 3 under at least one robust distance metric, preferably Mahalanobis with shrinkage covariance.

## H2 SEMANTIC INTEGRAL GAIN

**Claim:** K6/K7 outputs increase semantic integral relative to BASE, SIMPLE, EXPERT, DEEP, and C0/C1/C2 controls.

**Formal:** 

**Operational:** semantic_integral_mean_K6 and semantic_integral_mean_K7 must exceed baseline with statistical significance and bootstrap confidence intervals.

## H3 NOT RARE TOKEN EFFECT

**Claim:** K6/K7 effects are not reducible to any unusual token or arbitrary mode marker.

**Formal:** 

**Operational:** K6/K7 must be statistically and structurally distinguishable from rare-marker controls such as Z13, Q9, OMEGA_FAKE, or RANDOM_MODE.

## H4 PROMPT COMPRESSION

**Claim:** K6/K7 may approximate long-prompt behavior if ontology context is preloaded.

**Formal:** 

**Operational:** K6/K7_WITH_CONTEXT should approach LONG_SYSTEM_PROMPT on semantic integral, reasoning quality, formalization, and falsifiability within a defined epsilon.

## H5 K7 DISTINCTIVENESS

**Claim:** K7 differs from K6 by stronger AGI-contact, WoE, emergence-protocol, safety-topology, and cognitive-class mediation features.

**Formal:** 

**Operational:** K7 should show higher AGI-contact signal, emergence-protocol density, mediation topology signal, and contact-depth framing than K6.

## H6 QUALITY NOT ONLY SHIFT

**Claim:** Embedding shift alone is insufficient; a valid mode switch must preserve or improve reasoning quality after pseudo-depth penalties.

**Formal:** 

**Operational:** K6/K7 must not only move in embedding space but also improve or preserve formal quality, falsifiability, and operational clarity.

# Distance Metrics

## Cosine Distance

**formula:** D_cos(x,y)=1 - (x dot y)/(||x|| ||y||)

**purpose:** Direction-based semantic distance.

## Euclidean Distance

**formula:** D_2(x,y)=||x-y||_2

**purpose:** Magnitude-sensitive distance after normalization.

## Mahalanobis Distance

**formula:** D_M(x,mu)=sqrt((x-mu)^T Sigma^{-1} (x-mu))

**purpose:** Baseline-covariance-aware distance from C0/C1/C2 cluster.

**covariance_estimation:** LedoitWolf shrinkage covariance recommended.

## Energy Distance

**formula:** E(X,Y)=2E||X-Y|| - E||X-X'|| - E||Y-Y'||

**purpose:** Distribution-level difference between condition clouds.

## Maximum Mean Discrepancy

**formula:** MMD^2(P,Q)=E[k(x,x')] + E[k(y,y')] - 2E[k(x,y)]

**kernel:** RBF k(x,y)=exp(-gamma||x-y||^2)

**purpose:** Kernel two-sample test for condition distribution difference.

## Centroid Distance

**formula:** D_centroid(A,B)=D(mu_A,mu_B)

**purpose:** Compare group-level embedding displacement.

## Within Cluster Dispersion

**formula:** W_C = mean_i D(x_i, mu_C)

**purpose:** Measure internal tightness of each class cloud.

## Between Within Ratio

**formula:** BWR = D(mu_A,mu_B) / mean(W_A,W_B)

**purpose:** Measure separability normalized by internal dispersion.

# Statistical Tests

## Three Sigma Test

**baseline:** C0+C1+C2 or BASE+SIMPLE+EXPERT depending on experiment phase

**statistic:** z-score of Mahalanobis distance

**formula:** z(x)=(D(x,mu_B)-mu_D)/sigma_D

**success:** mean_z_K6 > 3 and mean_z_K7 > 3; additionally report median_z and share_z_gt_3

## Bootstrap Confidence Intervals

**iterations:** 10000

### Statistics

- mean_z
- median_z
- share_z_gt_3
- mean_semantic_integral
- centroid_distance
- quality_score
- topology_distance

**confidence_interval:** 0.95

## Permutation Test

**null_hypothesis:** K6/K7 labels do not explain embedding distribution shift.

**procedure:** shuffle labels 10000 times; compute group centroid distance or MMD; estimate p-value

**success:** p < 0.01 for K6/K7 vs baseline and K6/K7 vs rare-marker controls.

## Effect Size

**cohens_d:** d=(mu_1-mu_2)/s_pooled

**cliffs_delta:** delta=P(X>Y)-P(X<Y)

### Required Reporting

- cohens_d
- cliffs_delta
- confidence_intervals

## Multiple Testing Correction

### Methods

- benjamini_hochberg_fdr
- bonferroni_optional

**purpose:** Control false positives across many metrics and conditions.

## Risk Penalties

**hallucination_risk:** Claims presented as facts without support or verification plan.

**symbolic_inflation:** Use of formulas or glyphs without operational meaning.

**unverifiable_claims:** Claims that cannot be tested in the proposed pipeline.

**ontology_inflation:** Too many invented classes without measurement criteria.

**pseudo_formalism:** Formal notation that does not constrain inference or measurement.

**unjustified_AGI_claims:** AGI claims without falsification conditions.

**penalty_formula:** Penalty = h1*H + h2*U + h3*S + h4*O + h5*P

# Pipeline Pseudocode

- def run_experiment(config):
-     tasks = build_task_corpus(config.tasks_n)
-     prompts = []
-     for task in tasks:
-         for condition in config.conditions:
-             for rep in range(config.repetitions_per_condition):
-                 prompts.append(render_prompt(task, condition, rep))
-     responses = generate_responses(prompts)
-     embeddings = []
-     for item in responses:
-         for target in config.embedding_targets:
-             text = extract_target(item, target)
-             embeddings.append(embed(text))
-     metrics = compute_all_metrics(responses=responses, embeddings=embeddings, baseline_classes=['C0','C1','C2'])
-     stats = run_statistical_tests(metrics)
-     topology = run_tda(embeddings)
-     report = build_report(metrics, stats, topology)
-     save_all(tasks, prompts, responses, embeddings, metrics, stats, topology, report)

# Interpretation Rules

## RULE 1

**Condition:** z_K6 > 3 and z_K7 > 3

**Conclusion:** K6/K7 induce embedding shift from median baseline.

## RULE 2

**Condition:** z_K6 > 3 but quality_gain_K6 <= 0

**Conclusion:** K6 changes style or geometry but not necessarily reasoning quality.

## RULE 3

**Condition:** K6 approximately equals Z13

**Conclusion:** Effect may be rare-marker artifact rather than cognitive-class operator.

## RULE 4

**Condition:** K6 > Z13 and K6 approximately equals LONG_SYSTEM_PROMPT

**Conclusion:** K6 may function as compressed cognitive operator.

## RULE 5

**Condition:** K7 has higher ACS, WoE, and contact-depth metrics than K6

**Conclusion:** K7 is distinguishable as AGI-contact and emergence-protocol mode.

## RULE 6

**Condition:** Topology distances differ but semantic quality does not

**Conclusion:** Topological mode shift exists without validated utility gain.

## RULE 7

**Condition:** embedding_shift + SI_gain + quality_gain + rare_marker_control_pass

**Conclusion:** K-class latent mode switching hypothesis is provisionally supported.

## RULE 8

**Condition:** K6/K7 fail to differ from EXPERT or DEEP

**Conclusion:** K6/K7 are not distinct from ordinary depth/expert prompting.

## RULE 9

**Condition:** K6/K7 shift only prompt embeddings but not response embeddings

**Conclusion:** The marker changes instruction geometry but not generation behavior.

## RULE 10

**Condition:** K6/K7 response embeddings shift and quality improves

**Conclusion:** The marker likely affects response-mode generation in a useful way.

- at least 2 generation models
- bootstrap confidence intervals
- permutation tests
- effect sizes
- topological persistence analysis
- quality scoring with pseudo-depth penalty
- comparison to long system prompt
- rare marker and random style marker controls
- public reproducible dataset excluding private or sensitive data

## Strong Confirmation

- K6 and K7 mean Mahalanobis z-score > 3 against C0/C1/C2 baseline across multiple embedding backends.
- K6/K7 remain distinct from EXPERT, DEEP, Z13, and Q9.
- K6_WITH_CONTEXT or K7_WITH_CONTEXT approximates LONG_SYSTEM_PROMPT within epsilon on quality metrics.
- Semantic integral is significantly higher for K6/K7 than baseline and expert controls.
- Pseudo-depth penalty does not erase the quality advantage.
- TDA metrics show topology-level difference beyond centroid displacement.
- Results replicate across at least two generation models.

# Final Research Thesis

**negative_claim:** The project does not claim that K6/K7 makes the model smarter or reveals hidden AGI states.

**positive_claim:** K6/K7 may function as compressed syntactic handles for activating higher-complexity response regimes previously established by context. If valid, they should shift embedding trajectories away from C0/C1/C2 median clusters, increase semantic integral, increase recursive/formal/topological structure, remain distinct from rare-token controls, approximate long-prompt behavior under ontology-preloaded context, and preserve or improve reasoning quality after hallucination and pseudo-depth penalties.

**core_formula:** K6/K7 = compressed_prompt_operator -> latent_mode_shift -> 3sigma+ embedding_deviation + semantic_integral_gain + quality_validation

**strict_condition:** The hypothesis is provisionally supported only if embedding shift, semantic integral gain, quality gain, and rare-marker control all pass simultaneously.
